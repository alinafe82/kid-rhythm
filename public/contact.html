Contact and support

KidRhythm is maintained by Alinafe Matenda. For software problems or feature requests, use the public GitHub issue tracker.

Keep household information private

Issues are public. Describe the steps with invented examples and your browser version. Do not attach planner backups, child details, household routines, screenshots containing personal information, passwords or access tokens.

Private questions

The public maintainer profile at github.com/alinafe82 lists available contact options. This release has no private support inbox or guaranteed response time. Do not post a privacy request containing personal details in a public issue.

Lost planner data

The planner stores information on your device. The maintainer cannot access or recover it. If you saved a backup, use the planner’s import control on a private device. Read the privacy details before sharing any information.
